# Snooker Club Management System

A desktop application for managing snooker sessions, canteen sales,
inventory, payments, expenses, disputes, and reports.

## Development Rules

- Read docs/requirements.md before making changes.
- Do not change confirmed business rules without asking.
- Do not design the database unless explicitly requested.
- Do not implement everything at once.
- Work in small, testable stages.
- Keep the application suitable for a beginner-maintainable codebase.
- Prefer Python.
- Do not add paid services unless necessary.
- Do not add cloud hosting in the initial version.# public-snooker

Cost and architecture rules:

- Prefer local-first development.
- Do not use cloud hosting in the initial version.
- Do not add paid APIs.
- Do not add AI features unless explicitly requested.
- Do not add Firebase, Supabase, AWS, Azure, or other cloud services.
- Do not add a monthly subscription dependency.
- Use SQLite for local storage.
- Use free and open-source libraries where practical.
- Ask before adding any external service.
